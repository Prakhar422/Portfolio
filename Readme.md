# 🚀 Prakhar Garg - Developer Portfolio

A modern and responsive portfolio website built to showcase my projects, skills, experience, and journey as a MERN Stack Developer.

🌐 **Live Demo:** https://prakhargarg-portfolio.vercel.app/

📂 **Repository:** https://github.com/Prakhar422/Portfolio

---

## ✨ Features

* Modern futuristic UI with glassmorphism effects
* Fully responsive design for all devices
* Smooth scrolling navigation with active section highlighting
* Interactive project showcase using Swiper.js
* Animated components powered by Framer Motion
* Skills, education, and experience sections
* Downloadable resume
* Contact section with email integration
* Social media links and floating back-to-top button

## 📦 Installation

### Clone the repository

```bash
git clone https://github.com/Prakhar422/Portfolio.git
cd Portfolio
```

### Install dependencies

```bash
npm install
```

### Start development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```

### Preview production build

```bash
npm run preview
```
